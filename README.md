# otzivi-bot

Telegram-бот для приёма заявок: ниша → город → количество → оплата → проверка админом.
Тексты, кнопки, цена и ссылка на оплату меняются прямо в Telegram командой `/admin`.

## Запуск

1. Установите Python 3.10+.
2. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```
3. Скопируйте `config.env.example` в `config.env` и впишите `BOT_TOKEN` и `ADMIN_IDS`.
4. Запустите:
   ```
   python bot.py
   ```

На хостинге вместо файла `config.env` можно задать переменные окружения `BOT_TOKEN` и `ADMIN_IDS`.

## Файлы

- `bot.py` — сам бот.
- `requirements.txt` — зависимости.
- `config.env.example` — образец настроек.
- `bot.db` — создаётся автоматически (заказы, отзывы, настройки). При обновлении бота
  старая база дополняется недостающими колонками сама — удалять её не нужно.

## Команды

- `/start` — главное меню.
- `/cancel` — отменить текущий шаг.
- `/admin` — админ-панель (только для ID из `ADMIN_IDS`).
